# Titanic Survival Prediction using Machine Learning

This project predicts passenger survival on the Titanic dataset using multiple Machine Learning classification algorithms including Logistic Regression, K-Nearest Neighbors (KNN), and Decision Tree Classifier. The project includes complete data preprocessing, visualization, model evaluation, and comparison of algorithm performance.

---

## Features

- Loads and analyzes Titanic dataset
- Handles missing values automatically
- Encodes categorical data using Label Encoding
- Splits dataset into training and testing data
- Trains multiple Machine Learning models
- Predicts passenger survival
- Evaluates models using:
  - Accuracy Score
  - F1 Score
- Generates:
  - Confusion Matrix visualizations
  - Algorithm comparison bar graphs
- Identifies the best performing model
